Caladrius v0.3.1: the logo and its green in the interface, a typed table with subjects in columns and visible units, and a plot of the raw data before any analysis.

What changed since v0.3.0:

- **Logo and theme** (T-107): the logo in the window and task bar icon, on the welcome page and in the top bar; in the browser, a favicon and the logo on the loading screen. The logo's green is the accent of the light and dark themes (same values as the website, WCAG AA contrast tested). The version number shows under the logo and in the status bar; window and tab title `Caladrius - <project>`. The Windows `.exe` file icon in Explorer is not set yet.
- **Typed table** (T-108): with "Several subjects", a grid of times in rows and subjects in columns, with a number of subjects, subject names and an optional dose line; the times are typed once for every subject. A wide table pasted from a spreadsheet (times down the first column, one column per subject) is read the same way; one row per sample stays one click away. Typed grid, wide paste and long CSV give the same worksheet and the same NCA for every subject.
- **Units** (T-108): a menu next to every unit cell, in the typed table and the worksheet, lists the units the engine recognises (time s, min, h, d; any mass per volume for concentrations; any mass or mass per kg for doses, mg/kg included), from the new read-only command `units.check`, also on the CLI and the MCP server. The cell stays free text and the engine's checks show as soon as it loses the focus.
- **Raw data plot** (T-109): the worksheet screen plots the concentrations as entered against time, linear and semi-log side by side, before any analysis: one line, colour and marker shape per subject, points below the limit of quantification as hollow triangles, a legend that hides or shows a subject, values under the pointer. Read only, no computation.
- **Validation**: no engine number changed; conformance 48,955 of 48,955 values, as in v0.3.0.

Prebuilt binaries for Linux and Windows (desktop application, CLI, MCP server) are attached below with SHA-256 sums, next to the browser page `caladrius-web-v0.3.1.tar.gz`. No value in the conformance table comes from any commercial software; see the README.
