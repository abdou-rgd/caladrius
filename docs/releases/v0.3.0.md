Caladrius v0.3.0: the same interface in a browser tab, data typed or pasted without a CSV file, and multiple dosing.

What changed since v0.2.0:

- **Caladrius in the browser** (T-106): the desktop interface compiled to WebAssembly and drawn on a WebGL canvas, with the same engine and the same commands. Files are read inside the page and saved as downloads; settings stay in the browser's local storage; nothing is sent anywhere. Built by `cargo xtask web`; the page is attached below as `caladrius-web-v0.3.0.tar.gz` (a folder any static server can serve). On one test profile the NCA in the page equals `caladrius-cli nca.run` to the last digit; the oracle suite itself is not run inside WebAssembly.
- **Type or paste data** (T-103): a table of time, concentration, dose and an optional subject column, with units in the headers; Ctrl+V of spreadsheet cells (header line skipped, decimal comma accepted). The table goes through the same `data.preview` and `data.import` commands as a CSV file: typed, pasted and imported versions of one profile give byte-identical NCA results.
- **Multiple dosing and steady state** (T-049, T-051): dosing regimens (schedule, number of doses, steady state) for every one- and two-compartment model in the engine, the CLI and the MCP server, checked against the multiple-dosing oracle that v0.2.0 shipped.
- **Import**: text cells below the limit of quantification (`< LQ`, `BLQ`, `<LOQ`...) are read as BLQ points (T-097); a dose per kg of body weight gives clearances in L/time/kg and volumes in L/kg (T-098).
- **Validation**: conformance 48,955 of 48,955 values (32,036 at v0.2.0), with the same 16 documented differences; `clippy::indexing_slicing` denied in the four numerical crates (T-053).

Prebuilt binaries for Linux and Windows (desktop application, CLI, MCP server) are attached below with SHA-256 sums, next to the browser page. No value in the conformance table comes from any commercial software; see the README.
