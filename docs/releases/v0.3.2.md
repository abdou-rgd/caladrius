Caladrius v0.3.2: plots become objects of the workflow, like an NCA or a fit, saved in the project and exported as SVG.

What changed since v0.3.1:

- **Plots in the project tree** (T-110): a plot has its own page and its own setup: the source (a worksheet, or a fit already run), the subjects (ticked, or all), the scale (linear, semi-log or both), the layout (overlaid, or one panel per subject) and a title. It is named from its content, saved with the project, redrawn by "Run again" and marked stale when its source changes; a fit read by a plot cannot be removed before the plot.
- **Views of a fit**: from a stored fit result, a plot shows the fitted curve over the observations, observed against predicted, the residuals or the weighted residuals. "Keep a plot of this fit" under a fit result creates it in one click.
- **From the raw data**: "Keep as a plot" on the worksheet's raw data card (v0.3.1) turns the quick look into a plot object; "New plot" is also on the worksheet screen and in the New analysis menu.
- **SVG export**: a plot exports as an SVG file (light theme colours, one legend), through a save dialog on the desktop and a download in the browser. The points of a plot export as a table too.
- **Commands**: the new commands `plot.xy` and `export.plot` are available from the CLI and the MCP server, with the same parameters as in the interface.
- **Validation**: a plot only draws values already in the worksheet or in the stored fit result; nothing is computed, no numerical crate changed. Conformance 48,955 of 48,955 values, as in v0.3.1.

Prebuilt binaries for Linux and Windows (desktop application, CLI, MCP server) are attached below with SHA-256 sums, next to the browser page `caladrius-web-v0.3.2.tar.gz`. No value in the conformance table comes from any commercial software; see the README.
