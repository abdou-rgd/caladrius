# Caladrius logo

White bird with spread wings inside a dotted circle. The artwork was drawn by hand by Amina and commissioned by the repository owner; this directory holds the vectorised version (traced from the original PNG, cross removed, dotted circle completed behind the bird).

Credit: original drawing by Amina.

| file | use |
|---|---|
| `caladrius-logo.svg` | white on the original green (`#83d383`) background |
| `caladrius-logo-white.svg` | white on transparent, for dark backgrounds |
| `caladrius-logo-black.svg` | near-black (`#111`) on transparent, for light backgrounds |
| `caladrius-logo-mono.svg` | `currentColor` on transparent: follows the text colour, so it switches with the light or dark theme without swapping files |
| `caladrius-logo-small*.svg` | same four variants, simplified for small sizes (about 16 to 64 px): the finest feather lines are filled and the dots are larger and fewer |

All files share the same square `viewBox` (`0.5 89.5 1040 1040`). Use the `small` set below roughly 64 px, the full set above.
