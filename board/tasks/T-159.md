## Goal

Implement `specs/simulation.md` so that every test of T-158 passes, except the round trip (SIM-ORA-06), which waits for T-154.

1. **Philox4x32-10, in integers only**, on u32. The words are u64. The uniform is `(m as f64 + 0.5) * f64::EPSILON`.
   - Build 2⁻⁵² as `f64::EPSILON`, never with `powi`.
   - Use no `mul_add`.
2. **AS 241, from the spec's table only.** Use `libm::log` and `f64::sqrt`, with Horner as written.
   - **Do not open R's `qnorm.c`.**
   - Add one line to `ATTRIBUTION.md`: it credits AS 241 to Wichura (1988), says the constants were transcribed via R's GPL `src/nmath/qnorm.c`, and says that no code was taken.
3. **The Cholesky factor** (Cholesky–Banachiewicz) and η = L·z, with the stated left-to-right accumulation. P comes from `libm::exp`.
   - The input order of Ω is the lower triangle by rows. The fit must adopt the same order (a note for T-153).
4. **Each (replicate, subject) is a pure function.** The results are assembled in index order. A test entry point takes z^η and z^ε.
5. **The seal:** the seed is held as a decimal string, and the result carries `rng = "philox4x32-10/as241/v1"`. `seal::FORMAT` stays unchanged unless the hashed shape changes.
6. **Refusals before any output:**
   - `label_key_collision` and `duplicate_times` are checked on the design first.
   - A random effect on `tlag` or `dur` is refused.
   - Empty `random_effects` is `InvalidOption`.
   - A `pk3.*` id is `InvalidOption` until section 14 of `specs/models.md` is on the same branch.
7. **The digest and threads:**
   - add the SIM-DET-02 workload to the digest, as a deliberate change with its list of new steps;
   - add a test in `apps/` that gives the same result on 1 thread and on N threads.
