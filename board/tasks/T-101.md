## Goal

The gold of a frozen exercise is Caladrius's own output. Recompute the NCA of every frozen exercise with PKNCA 0.12.1, the version of the public oracle, with the same explicit options and the same C0 step for IV bolus data, and compare value by value at the conformance tolerance (relative 1e-6). A value beyond tolerance is a ledger entry and the exercise is replaced before the case freeze; the output is hashed in `MANIFEST.json`.
