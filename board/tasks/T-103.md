# T-103: Type or paste data into a new worksheet, without a CSV file

- **Role:** interface (caladrius-ui)
- **State:** to review
- **Depends on:** none
- **Source:** abdou, 2026-10-22: classmates of the pharmacokinetics M2 want to try Caladrius; a small set (one subject, 8 to 12 time/concentration points, one dose) must be typed or pasted in under two minutes, without writing a CSV file first

## Goal

Today a worksheet can only come from a CSV file (`import.rs`, `data.preview` then `data.import`). The worksheet screen edits existing cells (`data.set_cell`) but cannot start empty, add or remove rows, or take a paste.

A "Type or paste data" screen, reachable from the welcome screen, the top bar and the command palette:

- an editable table with the columns time, concentration and dose, and a subject column shown on request; units in the column headers (h, mg/L, mg by default, free text as in the CSV headers);
- add a row, remove a row, clear the table; the dose needs to be typed only once per subject (the worksheet already takes the first dose of a subject);
- a paste of several cells (Ctrl+V from a spreadsheet: tab-separated rows) fills the table from the cell in focus, adds rows when needed, skips a header line and accepts the decimal comma;
- "Create worksheet" turns the table into tab-separated text and sends it through the same commands as a file: `data.preview` (same checks, same messages, same "import anyway" box) then `data.import` with explicit roles and units. No new engine command: the CLI and the MCP server already do the same with `data.import` (golden rule 4).

## Allowed files

`crates/caladrius-ui/src/{entry.rs,entryflow.rs,app.rs,lib.rs,import.rs,palette.rs,tests_entry.rs}`, `crates/caladrius-ui/examples/snapshot.rs`, `docs/screens/` (one screenshot and its row), the card.

## Completion criterion

`cargo test -p caladrius-ui` passes with new tests, among them the equivalence test: the same synthetic profile typed into the table, pasted from a French spreadsheet (tabs, decimal comma, header line), and imported from a CSV text gives byte-identical `nca.run` results and the same worksheet export. A table with a check (duplicated time) shows the same check as the CSV import and needs the same acknowledgement. `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo xtask layers`, `cargo xtask lint`, `cargo xtask review`, `cargo xtask wasm` green; `docs/conformance.md` unchanged. Snapshot scenes of the empty and filled screen looked at.
