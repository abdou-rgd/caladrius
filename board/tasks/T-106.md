# T-106: Caladrius in the browser: the egui interface compiled to WebAssembly, for the website

- **Role:** interface (apps, caladrius-ui, xtask, CI)
- **State:** done
- **Depends on:** T-103
- **Source:** abdou, 2026-10-22: classmates of the pharmacokinetics M2 want to try Caladrius without installing anything; step 6 of the marching order (WebAssembly demo)

## Goal

The desktop interface, unchanged, running in a browser tab from the website (officina-dmpk.com, under `/app/`), with the same engine and the same commands. Files are read in the page and saved as downloads; nothing is sent anywhere. Out of scope in the browser: the CLI and the MCP server (they stay desktop programs).

- A new app crate `apps/caladrius-web` (layer App): eframe on WebGL (glow) on wasm32 only; `host.rs` answers the interface's requests (`PickCsv`, `OpenProject`, `SaveProject`, `SaveSettings`) through a `Browser` trait, tested natively with a fake browser; `browser.rs` is the web-sys side (file input, Blob download, local storage, tab title, a question before leaving with unsaved work, dropped files).
- `caladrius-ui`: `UiApp::set_can_quit(false)` takes "Quit" out of the File menu and the palette (a tab cannot close itself).
- `cargo xtask web [--out DIR]`: `cargo build --profile web` (release, `opt-level = "s"`, LTO, one codegen unit), `wasm-bindgen --target web` at the version of `Cargo.lock`, `wasm-opt -Os` when on the PATH, then `index.html`.
- CI: a `web` job (clippy for wasm32 on `caladrius-web`, `cargo xtask web`, artifact `caladrius-web`); the release workflow attaches `caladrius-web-<tag>.tar.gz`.

## Allowed files

`apps/caladrius-web/**`, root `Cargo.toml` (member and `[profile.web]` only), `Cargo.lock`, `xtask/src/{main.rs,layers.rs,wasm.rs,web.rs}`, `crates/caladrius-ui/src/{app.rs,palette.rs,projectmenu.rs,tests_project.rs}`, `.github/workflows/{ci.yml,release.yml}`, the board.

## Completion criterion

`cargo test -p caladrius-web` (9 tests: picker kinds, chosen and dropped CSV, unreadable file, save as download and saved state, refused download, downloaded project opens again chosen or dropped, no Quit, settings from local storage or language) and `cargo test -p caladrius-ui` green; `cargo clippy --target wasm32-unknown-unknown -p caladrius-web -- -D warnings` clean; `cargo xtask web` writes `target/web-page`; the page, served statically and opened in headless Chromium, imports a CSV through the file picker, takes a pasted French spreadsheet table, runs an NCA and downloads the project; the project's NCA values equal `caladrius-cli nca.run` on the same CSV to the last digit. CI commands of `CLAUDE.md` green; `docs/conformance.md` unchanged.
