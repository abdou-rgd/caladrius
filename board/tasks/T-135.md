- **Measure definitions.** `input_to_paint_ms`: from the call of the drag handler (`Screen::drag_handle`, the one a pointer drag calls) to the end of the frame that draws the result; the engine run (`nca.run`, `plot.scene`) is inside it. `frame_ms`: the CPU time of that frame's `App::ui` (the drag is made at the start of the frame, so it is inside too). GPU presentation is not counted. `first_frame_ms`: from the start of `main` to the end of the first `App::ui`, on edge_blq (the data is loaded before that frame). Drag k: subject `1 + k % 50`, start of λz on the last `[3,4,5,6][k % 4]` points with a positive concentration; the end handle stays at the engine's own last point. The final check compares each cell drawn (headline and "All parameters", 73 cells) with the text formatted from the raw JSON of the answer.
- **Keys.** Tab and Shift+Tab move through every control. Handles: Tab to a handle, then Left/Right move it one sample; or from anywhere Alt+Left/Alt+Right move the start handle and Alt+Shift+Left/Alt+Shift+Right the end handle, one sample (a sample with a positive concentration) per press. Include or exclude a point: Tab to its "Use for λz"/"Leave out" button in the table and press Space or Enter. Candidate rows: Tab to the row, Enter. `Ctrl+R` or `F5` run; `L` toggles semi-log and linear; `A` back to automatic; `P` opens or closes "All parameters"; `Alt+Up`/`Alt+Down` previous and next subject; `Ctrl+Shift+C` copies the results as tab-separated text with a header row (`Parameter`, `Value`, `Unit`, digits as shown); `Ctrl+Shift+D` copies the data table (`Time`, `Concentration`, `Role`). Letters act only when no text cell has the focus. Editing a cell: Tab into it, type, Enter or Tab to commit; the badge turns `stale`.
