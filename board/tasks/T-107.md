# T-107: The Caladrius logo and its green in the interface (desktop and browser)

- **Role:** interface (caladrius-ui, apps, xtask)
- **State:** done
- **Depends on:** T-106
- **Source:** abdou, 2026-10-22: now that the logo exists, put it in the interface and tint the interface with the logo's green (egui looked bland); in the browser, a favicon and a tab title that starts with "Caladrius" instead of the project name

## Goal

The interface carries the logo (window and task bar icon, welcome page, top bar) and uses the logo's green as its accent in both themes, with the same values as the website (officina `site/src/styles.css`: `--brand` `#83d383`, light `--accent` `#2c6e3a`, dark `--accent` `#83d383`) and WCAG AA contrast kept. No layout change, no plot colour change (series colours stay chosen for distinguishability), no engine, CLI, MCP or conformance change.

- `theme.json`: light and dark accent, hover, selected, border and neutral tones moved to the website's sage palette; two size tokens `logo_small` and `logo_large`.
- `assets/icons/`: PNG renderings of `assets/logo/` (256 px full drawing, 64 and 32 px simplified drawing, rounded corners), regenerated by `sh assets/icons/render.sh` (resvg 0.48.1).
- `caladrius-ui/src/logo.rs`: decodes the embedded PNGs (`png` crate, already in the lock file) and uploads them as textures; top bar and welcome page show them; the welcome page's first action is the primary (green) button.
- Window title and browser tab: `Caladrius - <project>` (unsaved marker ` *` at the end), program name first.
- Desktop window: icon from the 256 px rendering, app id `caladrius`. Browser page: favicon (32 and 256 px), touch icon, theme colour, the logo on the loading screen, loading background in the new theme tones; `cargo xtask web` copies the two icons next to `index.html`.

`crates/caladrius-ui/{Cargo.toml,src/theme.json,src/theme.rs,src/logo.rs,src/lib.rs,src/app.rs,src/projectfile.rs,src/tests.rs,src/tests_project.rs,examples/snapshot.rs}`, `assets/icons/**`, `assets/logo/README.md`, `apps/caladrius/src/main.rs`, `apps/caladrius-web/index.html`, `xtask/src/web.rs`, `Cargo.lock`, the board.
