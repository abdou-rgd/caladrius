The audit and fixes of T-119 to T-122 spent about 710,000 subagent tokens to realign figures; the READMEs hold 229 lines (caladrius, 6,175 words), 217 (apothicaire, 8,121), 127 (optchat, 2,423).

## Brief

**Goal.** Each README says only what does not change from one week to the next: what the project is, what it does, how to install and run it, where to read more, the license. Every figure lives in exactly one file, the one that owns it (generated where it can be), and a README points at it instead of copying it. The history, the failures and the lessons stay public, in dated files linked from the README.

**Deliverables.**
- Caladrius: `README.md` of at most 90 lines and no measured figure; the coverage table, the status counts and the "what went wrong" story move to `docs/validation.md` and a new `docs/history.md`; `cargo xtask review` reads its tables there, and a new rule `review-readme-figures` fails when `README.md` states a count or a ratio.
- Apothicaire: `README.md` of at most 90 lines; the benchmark results, the pinned runtimes, the gates and the known problems move to files under `docs/`; `tests/test_ledger.py` follows the quoted figures to their new file.
- OptChat: `README.md` of at most 60 lines, in French; the bench history v1 to v9 moves to `BENCH.md`.
- Umbrella README and the GitHub profile without project figures (the profile keeps the fixed facts of the CV); the PC README copied again.
- The rule written once: `AGENTS.md` (within its 199 lines) and one line in the `CLAUDE.md` of apothicaire and optchat: "a README states no figure that a run can change; the figure lives in its owner file".

**Claims touched.** No published figure changes value. Figures leave the four READMEs and the profile for their owner files; the site keeps its figures as they are (its redesign is T-123).

**Done when.**
- The line counts above hold, and `grep` finds no ratio or count in the four READMEs.
- `cargo xtask lint` and `review` are green, and `review-readme-figures` has a test that fails on a README with a ratio.
- `python -m unittest tests.test_ledger` is green in apothicaire.
- Nothing is lost: every paragraph that leaves a README is found, unchanged or shortened, in its new file (checked by the audit), and no link of the four repositories, the site or the notes points at a removed README section.
- The audit is done, the outcome is written, and the learning page is linked.
