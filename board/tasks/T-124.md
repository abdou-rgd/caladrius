## Brief

**Goal.** Each README says only what does not change from one week to the next: what the project is, what it does, how to install and run it, where to read more, the license. Every figure lives in exactly one file, the one that owns it (generated where it can be), and a README points at it instead of copying it. The history, the failures and the lessons stay public, in dated files linked from the README.

**Deliverables.**
- Caladrius: `README.md` of at most 90 lines and no measured figure; the coverage table, the status counts and the "what went wrong" story move to `docs/validation.md` and a new `docs/history.md`; `cargo xtask review` reads its tables there, and a new rule `review-readme-figures` fails when `README.md` states a count or a ratio.
- Apothicaire: `README.md` of at most 90 lines; the benchmark results, the pinned runtimes, the gates and the known problems move to files under `docs/`; `tests/test_ledger.py` follows the quoted figures to their new file.
- OptChat: `README.md` of at most 60 lines; the bench history v1 to v9 moves to `BENCH.md`; both in English (Abdou, 2026-10-29: everything in English).
- Umbrella README and the GitHub profile without project figures (the profile keeps the fixed facts of the CV); the PC README copied again.
- The rule written once: `AGENTS.md` (within its 199 lines) and one line in the `CLAUDE.md` of apothicaire and optchat: "a README states no figure that a run can change; the figure lives in its owner file".

**Claims touched.** No published figure changes value. Figures leave the four READMEs and the profile for their owner files; the site keeps its figures as they are (its redesign is T-123).

## Outcome

**Results.**
- READMEs: Caladrius 229 -> 89 lines, Apothicaire 217 -> 81, OptChat 127 lines in French -> 54 in English, the umbrella 32 -> 35 lines; none states a measured figure, and the profile lost its three project figures. The four sections the site links to on the Caladrius README stay.
- Nothing lost, checked mechanically by the orchestrator: of the lines of 40 characters or more removed from a README, Caladrius 112 of 118 and Apothicaire 120 of 131 are byte-identical in a new file, and every other one is a moved line whose "below" or path became a link; the umbrella 0 lost; OptChat, translated, keeps all 106 distinct numbers of its old README in `BENCH.md` or the README.
- New homes: Caladrius `docs/validation.md` (coverage and status tables), `docs/history.md`, `docs/usage.md`; Apothicaire seven files under `docs/`; OptChat `BENCH.md`; the umbrella `HISTORY.md`.
- The rule is written once (`AGENTS.md` section 5, the `CLAUDE.md` of apothicaire and optchat) and enforced in Caladrius: `review-readme-figures` fails on a ratio, a percentage, a thousands-separated number or a count. `cargo test -p xtask` 187 passed and the 3 known PermissionDenied of T-053; `cargo xtask lint` ok (1417 files); `cargo xtask review` 0 failures and the 2 notes main already had; `python -m unittest tests.test_ledger` 18 tests OK; the site builds.
- Audit (reviewer, Fable): verdict "approve with fixes"; 1 major (a bare count such as "48955 validated values" passed the rule that `AGENTS.md` said catches counts), 6 minors (a coverage heading whose absence was only a note, one README sentence stronger than `docs/reproducibility.md`, the site's "Why Rust" link whose paragraph had moved, a softened gate v3 sentence, three stale pointers in the moved Caladrius docs, the case of `none`), 1 note (push order). All fixed (8ea995d, 559d1e8 here; apothicaire e6c6b19, optchat 46c6989, umbrella e2fee64); the two counter-examples of the audit now fail `review`.
- Cost: about 913,000 subagent tokens (T-125 292k, T-126 161k, T-127 110k, audit 220k, fix 130k), against about 710,000 for the one realignment of T-119 to T-122 that started this iteration.

**Lessons.** Moving text verbatim made "nothing lost" a script instead of a reading, so the Fable audit could spend its budget on the code and the new sentences; that is where it found the one real gap. The first version of the rule claimed more than it caught, and only an outside reader saw it: the contract sentence was written before the code it described was tested against a counter-example.

**Bolder next step.** One detector for every README: expose the rule as `cargo xtask review --readme PATH` and have the CI of apothicaire and optchat, which already build Caladrius from source, run it on their own README, so the four READMEs are guarded by one implementation instead of a sentence in two `CLAUDE.md`. Proposed to Abdou, not started.
