## Goal

Observed in the benchmark: ex12 made six `analysis_compare` calls with a = b = 3, then showed the raw text of an unexecuted tool call as its answer (`../agent/README.md:78`). There is no a ≠ b guard and no de-duplication in `../agent/apothicaire.py:371-390`, and the last round has no tools (`../optchat/optchat.py:524-527`; 8 rounds, `:45`).

Add deterministic guards: refuse `analysis_compare` with a = b, refuse an identical call repeated in the same turn, and replace a final answer that is a tool-call payload with a fixed message.
