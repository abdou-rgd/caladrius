# T-182: The plot layer: the engine's plot scene drawn by Vega-Lite on a canvas

- **Iteration:** T-178
- **Role:** interface
- **State:** to review
- **Depends on:** T-179 (`plot.scene` on `front/int`)

## Goal

A package `@caladrius/plot` (`apps/caladrius-plot/`) that draws a `plot.scene` answer with Vega-Lite (canvas renderer) and never computes a number a person reads.

1. **The scene is the input.** `src/scene.ts` already holds the TypeScript types of the `plot.scene` result (from its `result_schema`). A logarithmic axis is already in log10: its `min`, `max`, tick values and the points are decades; the tick label is the value in data units, written by the engine.
2. **Pure spec builder** `src/spec.ts`: `sceneToVegaLite(scene: PlotScene, options: SpecOptions): TopLevelSpec` (Vega-Lite types from `vega-lite`). One Vega-Lite view per panel, `concat` with `columns` (1 or 2, an option), each view:
   - x and y scales `linear`, `domain: [min, max]`, `nice: false`, `zero: false`, `clamp` off (points outside are the engine's choice);
   - axis `values` = the tick values of the scene, and the label of each tick is the engine's label through `labelExpr` (a chain of `datum.value === v ? 'label' : …` with `v` written by `JSON.stringify`, so the double is exact); `format` and `formatType` never used;
   - axis titles from the scene; the panel title above;
   - series by `style`: `points` as circles, `line` as a line ordered by the point order of the scene (an `order` field holding the index), `line_points` both; a BLQ point (`blq: true`) as an open triangle;
   - colours by role and slot from `options.colors` (keys `observed`, `predicted`, `fit`, `selected`, `start`, `replaced`, `other`, `subjects: string[]`, `grid`, `background`, `text`, `muted`); `subject` series use `subjects[slot % n]`; `predicted` and `lambda_z_fit` lines use `fit`; `lambda_z_used` uses `selected`; `lambda_z_start` uses `start`; `excluded` uses `muted` hollow; `replaced` uses `replaced`. Legend off in Vega (the component draws it in HTML from `scene.legend`);
   - `guide` (`identity` or `zero`) as a rule from `from` to `to`;
   - `empty` panels: a text mark with the engine's sentence;
   - **overlay** (`options.overlay?: { name: string; points: { x: number; y: number }[] }[]`): curves given in data units by the app (the live preview of initial estimates, from `model.simulate`). Drawn as dashed `predicted`-coloured lines. On a log panel they go through a Vega-Lite `calculate` of `log(datum.y) / LN10` with non-positive values filtered out first: this is a scale mapping (drawing), the only arithmetic allowed in the package, and it is written once in one function with a comment saying so;
   - tooltips: only text given by the app (`options.tooltip?: (series: string, point: ScenePoint, panel: number) => string`, precomputed into a `tip` field); no Vega default tooltip formatting;
   - no `aggregate`, `bin`, `loess`, `regression`, `density`, `quantile`, `timeUnit` or `format` anywhere.
3. **Component** `src/PlotView.tsx`: `export function PlotView(props: { scene: PlotScene; overlay?: Overlay[]; columns?: 1 | 2; height?: number; tooltip?: …; onPointClick?: (series: string, index: number, panel: number) => void })`. Reads the theme colours from the CSS variables of the page (`getComputedStyle(document.documentElement)`: `--c-series-observed`, `--c-series-selected`, `--c-series-start`, `--c-series-fit`, `--c-series-replaced`, `--c-series-other`, `--c-series-subjects-0..`, `--c-plot-background`, `--c-plot-grid`, `--c-text`, `--c-text-muted`), re-renders on a theme change (`data-theme` attribute or `prefers-color-scheme`), sizes itself to its container width (`ResizeObserver`), renders with `vega`'s `View` (`renderer: 'canvas'`), finalizes the view on unmount and on every new spec (no leak). Under the canvas, in HTML: the legend from `scene.legend` (with `below_limit`), each panel's `hidden.note`, and `scene.notes`. The canvas gets `role="img"` and an `aria-label` from the scene title and panel titles.
4. **Rule 6.** A scene with no panel, a panel with no series, an empty series, a NaN in a point: a sentence or nothing, never a thrown error; an error boundary around the view shows a sentence.
5. **Exports** (`src/index.ts`): `PlotView`, `sceneToVegaLite`, the scene types, `type Overlay`, `type PlotColors`.
