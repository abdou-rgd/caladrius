# T-110: Plots as objects of the workflow

- **Role:** interface (caladrius-project, caladrius-engine commands, caladrius-ui, apps)
- **State:** to review
- **Depends on:** T-109
- **Source:** abdou, 2026-10-22: everything one does with the data belongs to the workflow, like the NCA and the fits; plots should be objects too, with their own setup (which subjects, scale, overlaid or one panel per subject), saved in the project and exportable

## Goal

An XY plot is an analysis object like an NCA or a fit: created from a worksheet or from a fit already run, named from its content, saved with the project, marked stale when its source changes, redrawn by `analysis.run`, exported as SVG.

1. `caladrius-project`: a fourth analysis kind `plot` (`PlotSpec`: source worksheet or fit with a view, subjects or all, scale linear / log / both, layout overlaid / one panel per subject, title) and its result (`PlotRun`: title, panels with axes, units and series of points as they are in the source, BLQ flagged, notes). A plot of a fit is stale when the fit runs again (`source_changed`), when the fit itself is stale (`source_stale`) or when it is gone (`source_missing`); a fit shown by a plot cannot be removed before the plot.
2. `caladrius-engine`: `plot.xy` (stable id, golden rule 4) draws and stores the plot; `export.plot` gives the SVG of the stored panels (light theme colours, one legend, panel size in pixels); `export.table` gains `plot.points`. Nothing is computed: worksheet cells, or the observed, predicted, residual and weighted residual values and the smooth curve of the stored fit result. No numerical crate is touched.
3. `caladrius-ui`: plots in the project tree, a plot page (source, subjects ticked or all, scale, layout, title, export SVG) with the panels drawn; "New plot" from the worksheet screen and the New analysis menu, "Plot" buttons on a fit result; the worksheet's raw-data card (T-109) stays as the quick look and gains the shortcut. Desktop and browser save the SVG (file dialog, download).
