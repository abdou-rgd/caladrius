   - how it is minimised, written as rules the engine can follow with what `caladrius-fit` already has (Gauss-Newton or Levenberg-Marquardt steps, FIT-CNV-*).    - initial estimates for the error parameters;
   - convergence, and what is refused, each with a sentence:
     - σ_i ≤ 0 at an observation (the proportional model with ŷ ≤ 0);
     - an exact fit, where the likelihood is unbounded;
     - N ≤ P + Q;
     - an error parameter going to its bound;

     - −2LL;
     - AIC = −2LL + 2·(P + Q) and BIC = −2LL + (P + Q)·ln N, next to the WRSS forms of FIT-OUT-07, never replacing them;
