## Brief

**Goal.** Choose the stack of the Caladrius interface on measures rather than on opinions. Build the same NCA screen in three stacks on the real engine: the data, the λz range chosen on the semi-log plot, then the results with their flags and their seals. Measure the three with one script, audit them, and write a decision note with an amendment of `AGENTS.md` for Abdou to decide. The demo of 2026-11-17 stays on the current egui interface. Before 2026-11-18, only `docs/` and `board/` of this iteration reach `main`. Code stays on branches.

**What the survey gives** (facts dated 2026-11-06 in the survey; inferences marked).
- Three finalists: egui 0.37 pushed further (egui_tiles for panels), Tauri 2 with a TypeScript front, and Leptos with Tauri. Ruled out: Slint (its authors advise against its web target), Iced (second-rank web), GPUI (no wasm yet), Dioxus (0.8 still alpha; it is Leptos's fallback) and Electron (installer size).
- egui_plot has neither a true log scale nor an SVG export. Tauri 2 on Linux (WebKitGTK) can show blank windows and silently fall back to software WebGL, so the prototypes use no WebGL plots and get a Linux check.
- Ideas from open projects: the panel layout as a saved file (Rerun's blueprint); an up-to-date or stale state on each result (marimo); a hash per step and a diff between two versions of an analysis (DVC); setting the half-life range by clicking the plot (aNCA).
- Inference: Caladrius will not stand out by its stack. It will stand out by what the stack shows: the seal under every number, the replayable history, the stale state.

**Where this card departs from the survey.**
1. The plot scene already half exists. `crates/caladrius-engine/src/svg.rs` (T-110) places points, nice ticks and decades, and draws a log axis that hides non-positive values, for `export.plot`. What is missing is the scene as data, drawn alike by the screen and by the export. Today the screen uses egui_plot and the export uses `svg.rs`: one plot, two drawings. T-133 extracts that scene; it does not start a crate from nothing.
2. React 19 rather than Svelte 5 as the TypeScript candidate, for three reasons. The site is already Vite + React + TypeScript, so the app and the site can share one token set and the same components. Agents write React most reliably, which the survey also says. dockview has an official React package. Svelte's fine-grained signals gain little at the size of one NCA screen. Abdou chose React on 2026-11-06.
3. No chart library in the prototypes. All three draw the same T-133 scene, with the egui painter or as SVG in the DOM. The comparison then measures the stack and not a chart library, and the export matches the screen by construction. npm brings only React, dockview and Vite.
4. Number formatting lives in `crates/caladrius-ui/src/fmt.rs` today. A web front calls that same code through the bridge (T-134) and does not rewrite it in TypeScript.
5. Clean room. The survey suggests studying a commercial NCA product's workflow; we do not (rule 1). `interface` works from `specs/ux.md` and the chosen mockup.

**Measures.** Same PC, same dataset and one script reading the JSON that each prototype writes. Each figure comes with its denominator.
- Cold start (median of 10 runs) and shipped size: the Windows executable or installer, and the wasm and JS for the browser.
- Time per frame while dragging the λz range on 50 subjects of 20 points, made by `model.simulate` with its command line committed: p50 and p95 over the frames recorded.
- Memory after loading and after 100 drags.
- Keyboard only: steps of the task done without a mouse, k of n. Accessibility tree dumped: named controls, k of n.
- The results table pasted into a spreadsheet: columns and digits intact.
- Offscreen screenshots, automated, so rule 8 still holds.
- Cells on screen equal to the engine's formatted value, k of n. The SVG export against the screen, as a pixel difference.
- The work: subagent tokens and correction rounds after the first version, with the same brief and the same model for each stack.
- Time from a style change to its display.
- Linux in CI (Ubuntu, xvfb), if Abdou lets the prototype branches be pushed; otherwise "not measured".
