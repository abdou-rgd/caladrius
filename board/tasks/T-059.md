# T-059: Apothicaire: send the units option to nca_run so CL and V come out in L/h and L

- **Role:** apothicaire (repository abdou-rgd/apothicaire, `../agent` locally)
- **State:** done
- **Depends on:** none
- **Source:** red-team triage of 2026-10-19, row RT-E4 (confirmed, partly), project Library `red-team/triage.md`; reports Gemini 4 Argon E3
- **Batch:** demo quick fixes (T-059 to T-062)

## Goal

CL and V show as "dose unit/(h*ng/mL)" because Apothicaire never sends `options.units` to `nca_run` (`../agent/apothicaire.py:39`, `NCA_OPTIONS_KEPT` without `units`, and `:198`). The engine already converts CL and volumes to litres when it gets them (`crates/caladrius-engine/src/schema.rs:278-289`, `crates/caladrius-nca/src/lib.rs:248`). The value is not wrong by a factor 1,000, as the Gemini report says: it is not converted.

Send the worksheet's dose, time and concentration units to `nca_run`, and keep the `param_unit` labels consistent with what the engine returns.

## Allowed files

`../agent/apothicaire.py`, `../agent/tests/test_agent_gate.py`, `../agent/tests/test_agent_gate_v2.py`, `../agent/tests/golden/`, the card.

## Completion criterion

`python -m unittest discover -s tests` passes in `../agent`. An agent test on a mg dose and an ng/mL worksheet gets CL in L/h and Vz in L from the engine.
