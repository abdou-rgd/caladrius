# T-075: OptChat: make long messages fully readable through the memory tools

- **Role:** optchat (repository abdou-rgd/optchat, `../optchat` locally)
- **State:** todo
- **Depends on:** none
- **Source:** red-team triage of 2026-10-19, row RT-C2 (confirmed), project Library `red-team/triage.md`; reports DeepSeek 4.1 Flash C1, Gemini 4 Argon C1, Astra6 C2, ChatGPT Sol6.1 C3

## Goal

Tool results lose their numbers in memory: the summary instruction says "never copy it", text is cut at 6,000 characters before the summary, and a line is at most 512 bytes (`../optchat/optchat.py:36-40`, `:68`, `:496`). The zoom stops at 8,000 characters and `read_message` at 12,000, with no pagination (`:484-500`). The tail of a long message stays on disk, but no tool reaches it.

Add an offset to `read_message` (and to the zoom), and say in the tool result when the text was cut.

## Allowed files

`../optchat/optchat.py`, its tests, the card.

## Completion criterion

Test: a 30,000-character message is read whole in three calls, and the cut is announced in each partial result.
