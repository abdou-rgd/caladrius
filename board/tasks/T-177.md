# T-177: Proposal: own the maths library (`caladrius-math`), with a digest per function and a measured accuracy

- **Role:** engine (the crate and the call sites), oracle (the test vectors and the accuracy script), interface (`xtask`, CI)
- **State:** todo
- **Depends on:** T-111
- **Source:** Abdou, in chat, 2026-11-12: a proposal to discuss before any work, after a conversation on the reproducibility of the population fit. Nothing is started; this card is the proposal. It does not belong to an iteration until the orchestrator places it in one.

## Why

T-111 made the engine return the same bits on Linux, Windows, macOS and wasm32, by routing every platform-dependent float function through the pure Rust `libm` crate, pinned `=0.2.16`, and banning the standard ones in `clippy.toml`. That holds, and the CI digest proves it for what the workload reaches. Three things are still taken on trust rather than checked:

1. **The source of the guarantee lives outside the repository.** Golden rule 10 rests on the code of a third-party crate: its target-specific paths (`cfg(target_arch)`, intrinsics) and its features decide whether one function runs the same instructions on every target. T-111 read them for the functions used and found only exactly rounded operations there. A reviewer of Caladrius cannot check that in this repository, and a pinned version is not a reviewed source.
2. **The digest covers the workload, not the functions.** `docs/reproducibility.md` lists it as a gap: a command or an option the workload never runs has no cross-machine check. The population fit (T-153, T-154) and the simulator (T-159) call `exp`, `log` and `expm1` on arguments (large negative exponents, the tails of AS 241, `ln_gamma` through `sin`) that the NCA and individual-fit cases may never reach.
3. **The accuracy of `libm` is quoted, not measured.** "Below 1 ulp" comes from the upstream documentation. `docs/validation.md` cannot cite it as a Caladrius figure.

The population objective makes all three matter more: FOCEI decides its BFGS steps and its stopping rule from sums over subjects of `log` and `exp` terms, so one ulp can change the number of iterations (the Indometh trace of 6 entries against 5 in T-111 was exactly that).

## Goal

1. **`caladrius-math`, a new L0 crate with no dependency.**
   - It holds the seven functions the numerical code calls today, and nothing else: `exp` (75 call sites), `log` (25), `expm1` (11), `pow` (10), `log10` (6), `log1p` (1) and `sin` (1, in `caladrius-fit/src/stats.rs`, the reflection of `ln_gamma`). Counted on `main` at `da68b70` with `grep -rhoE 'libm::[a-z0-9_]+' crates xtask`.
   - Each function is ported from `libm` 0.2.16 (MIT, itself a port of musl and FreeBSD), with every target-specific path removed, so that one source compiles to the same instructions' semantics on every target. A row in `ATTRIBUTION.md` and the license text in the same commit (golden rule 1).
   - The port must be bit for bit the pinned `libm`: the existing workload digest (`2335edbe9a69…`) and `docs/conformance.md` stay unchanged. A different digest means the port is wrong, not that the digest moves.
   - `powi` and `sq` from `caladrius-fit/src/arith.rs` move into it, and a deterministic `max`/`min` (one rule for +0 and -0) closes the known gap of rule 10 on the sign of a zero.
   - `nca`, `models`, `fit`, `engine` and `xtask` depend on `caladrius-math` instead of `libm`. The `reason` texts of `clippy.toml` name `caladrius_math::exp` and so on. `cargo xtask layers` registers the crate.
2. **A digest per function, beside the workload digest.**
   - A fixed list of arguments per function: the special values (±0, ±infinity, NaN, subnormals, the smallest and largest normal numbers, the overflow and underflow thresholds, arguments next to 1 for `log` and `log1p`, next to 0 for `expm1`), then a sweep of a few million arguments drawn by the engine's Philox generator (`specs/simulation.md`) from a fixed seed, over the ranges each function meets in PK (for example `exp` on [-745, 710]).
   - `cargo xtask digest` prints one SHA-256 per function. The four CI legs compare them like the workload digest. This removes the "commands the workload does not reach" gap for the arithmetic itself.
   - NaN outputs are written as one canonical text before hashing, so a NaN payload that differs between targets cannot split the digest.
3. **The accuracy, measured.**
   - An R script in `oracle/` evaluates the same arguments with `Rmpfr` (MPFR at 200 bits) and writes the correctly rounded results. A testkit test reports, per function, the largest error in ulp and the share of correctly rounded results.
   - These figures go into `docs/validation.md`, their owner file; the README states none (`review-readme-figures`).
4. **No numerical dependency besides `caladrius-math`.** A `cargo xtask lint` rule reads `cargo metadata` and fails when a crate of L0 to L2 depends on a crate that is not on an allow-list (today: `serde`, `serde_json`). A new numerical dependency then has to be decided, not added in passing: clippy's ban covers this repository's code, never the code of a dependency.

## Out of scope here (bolder next steps, for Abdou to decide)

- **Correct rounding.** Porting the correctly rounded `exp` and `log` of the CORE-MATH project (MIT). The same bits everywhere would then follow from the IEEE definition rather than from one shared source, and would match any other correctly rounded library. It changes the workload digest and perhaps conformance, so it is its own card, after this one is green.
- **An interval oracle.** Arbitrary-precision interval arithmetic in the testkit, giving a certified bound on the error of a whole FOCEI objective evaluation, not only of one function.

## Allowed files

`Cargo.toml`, `Cargo.lock`, `clippy.toml`, `crates/caladrius-math` (new), the manifests and `libm::` call sites of `crates/caladrius-{nca,models,fit,engine}`, `crates/caladrius-fit/src/arith.rs`, `crates/caladrius-digest`, `crates/caladrius-testkit` (the accuracy test), `oracle/` (the R script and its output), `xtask` (`layers`, `lint`, `digest`), `.github/workflows/ci.yml`, `AGENTS.md` (rule 10, the repository map), `ATTRIBUTION.md`, `docs/reproducibility.md`, `docs/validation.md`, the board.

## Completion criterion

`cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `cargo xtask layers`, `lint`, `review` and `wasm` clean; `cargo xtask conformance` leaves `docs/conformance.md` unchanged; the workload digest is still `2335edbe9a69…`; the per-function digests are the same on the four CI legs; `cargo tree -p caladrius-fit` no longer lists `libm`; `docs/validation.md` has the ulp table.
