## Goal

Abdou asked, on 2026-11-09, to remove Onizuka and to weigh six points of the OLS Prime setup against this one. Each point is taken or kept for a stated reason:

- **Where the contract lives.** Adapted. `AGENTS.md` stays the contract, because `cargo xtask lint` reads it (`agents-table`, `contract-size`, the board rules) and other tools read `AGENTS.md` by convention. `CLAUDE.md` now imports it (`@AGENTS.md`), so it reaches every session and every subagent without a read. - **Where the briefs live.** Kept. A board card has a state, a thread, a row in `INDEX.md` and lint checks; an OLS Prime brief file has none of these.
- **Commits.** Taken, adapted. Subagents no longer commit, update `LOG.md` or switch branches. The orchestrator commits after it has re-run the completion command and, for the three numerical crates, after the review, which now reads an uncommitted diff. It does not ask Abdou before each commit as OLS Prime does: section 10, rule 1 needs a commit after each task, so that a cut session resumes from the board. Pushes stay Abdou's.
- **Language.** Taken. The repository stays in English; the conversation is in Abdou's language. The contradiction between the start of `AGENTS.md` and section 8 is gone.
- **Report length.** Kept: at most ten lines (five for the janitor). A short report is what lets the orchestrator read little (section 10, rule 3); OLS Prime only says "short".
- **Onizuka.** Removed: its file and its row in section 8. The learning page becomes optional: the orchestrator writes it when Abdou asks for one. Otherwise the `**Learning page.**` line says `none` and why. The board lint already accepts that.

Also fixed: the stale path in `board/RESUME.md` (`apothicaire\caladrius` became `officina\caladrius`).
