# T-131: Inventory of the current interface, screen by screen

- **Role:** interface
- **State:** to review
- **Iteration:** T-130
- **Depends on:** none
- **Source:** iteration 2 (T-130), wave 1.

## Goal

`docs/interface-inventory.md` describes what a new interface would have to port. It has one section per screen or panel of `crates/caladrius-ui`, `apps/caladrius` and `apps/caladrius-web`: data entry and paste, import, the raw plot, plot pages, NCA, fit, model choice, simulation, settings, the project tree, "Verify a project", the command palette, and any other screen found. Each section states:

- the source files and their line counts;
- the command ids it calls, as written in the registry;
- the UI state it keeps, and whether that state is serialised;
- the numbers it formats, and through which function of `fmt.rs`;
- its tests (`egui_kittest`) and its snapshot examples;
- the `specs/ux.md` requirements it serves (UX-FR, UX-REQ, UX-LZ, UX-LOG, UX-IMP);
- what a port to another stack would cost, in plain words.

Two cross-cutting sections close the file:

- **Plots.** Where the screen and the `export.plot` SVG (`crates/caladrius-engine/src/svg.rs`) draw the same plot differently: ticks, log axis, hidden points, colours, legend. This is the input of T-133.
- **Platform code.** What `apps/caladrius` and `apps/caladrius-web` do that is not interface: files, the clipboard, fonts, the logo, wasm glue. This is the input of T-134.

## Allowed files

Read: `crates/`, `apps/`, `specs/ux.md`, `docs/`, `xtask/`. Write: `docs/interface-inventory.md` (new) and this card. No code change. Clean room: do not open `private/`.

## Completion criterion

- `docs/interface-inventory.md` exists, with a section for every source file of `crates/caladrius-ui/src` that draws a screen. A file that is not a screen, such as `fmt.rs` or `theme.rs`, is listed once under the section that uses it.
- Every command id in the inventory appears in the registry. Checked by a `grep` of each id in `crates/caladrius-engine/src`, and the report gives the count, k of k.
- `cargo xtask lint` passes.
- A report of at most ten lines: the screens and their total lines, the commands used and the registry's commands that no screen calls, the three costliest screens to port, and one bolder next step.
