## Goal

Build the NCA screen of the shared brief as a web front: React 19, TypeScript and Vite, with panels in `dockview`. The plot is SVG in the DOM, drawn from `plot.scene`. The engine is reached through the TypeScript client of `apps/caladrius-bridge/ts/`. The same build runs in a browser (`WorkerTransport`, engine in wasm) and in the Tauri 2 shell of `apps/caladrius-tauri` (`TauriTransport`). It runs on branch `iter2/react`, in the worktree `C:\Users\abdou\caladrius-iter2\react`.

npm brings only React, React DOM, dockview, Vite and its React plugin, TypeScript and `@tauri-apps/api`. There is no chart library, no CSS framework, no web font and no icon set. The colours come from `theme.json`, turned into CSS variables at build time.
