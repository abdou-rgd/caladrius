## Goal

Today the bridge of T-134 (`apps/caladrius-bridge` on `iter2/base`, worktree `C:\Users\abdou\caladrius-iter2\scene`) knows one call, `execute(request) -> sealed answer`. A population fit lasts minutes. Write a one-page spec, `docs/long-running-commands.md`, that says:

1. **The shape.** `fit.start` (and later any long command) returns a job id at once. The engine then emits one progress event per iteration: the job id, the iteration number, the OFV (or the WRSS of an individual fit), the current parameters. Progress events are not sealed and never enter the history. `fit.cancel` with the job id asks the job to stop. The job ends with exactly one of: the sealed answer, an error, or "cancelled after iteration n", which is a sentence and never a panic (rule 6).
2. **The engine's side.** The engine checks a cancel request between two iterations and never inside one. A run with a progress observer that never cancels returns the same bytes and the same seal as a run without one (rule 10). Say what the engine API looks like for this, so that T-143 implements it.
3. **The hard case to settle.** In a Web Worker, a synchronous engine call blocks the worker's event loop, so a cancel sent by `postMessage` is not read until the call returns; SharedArrayBuffer is off in WebKitGTK (Fable message, placement C). Choose and justify one way: the host drives the job one iteration at a time (the engine keeps the iteration state as a value and the worker yields between steps), or `Worker.terminate()` with a re-instantiated module, or another. The choice shapes T-143, so state it plainly.
4. **Three transports, none implemented.** Tauri: a `#[tauri::command(async)]` with a `tauri::ipc::Channel` for the events and an `AtomicBool` in managed state for the cancel. Web Worker: messages in both directions, with the shape above. MCP: how the same shape maps onto the protocol's progress and cancellation notifications, so that Apothicaire can follow a fit. Cite the primary documents with their dates.
5. **What is out.** Several jobs at once, resuming after a crash, partial answers: each is either specified or explicitly left out.

One page: about 80 lines. English, no figure that is not sourced.
