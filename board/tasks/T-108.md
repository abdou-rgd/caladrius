# T-108: Paste a wide table into the typed table, and show the recognised units

- **Role:** interface (caladrius-ui), with one read-only engine command (`units.check`)
- **State:** to review
- **Depends on:** T-103
- **Source:** abdou, 2026-10-22: a profile of several subjects copied from a course handout (times down the first column, one column per subject) and pasted into "Type or paste data" filled the table cell for cell, which made no sense; then: show the units Caladrius accepts next to the unit cells instead of leaving them to guesswork

## Goal

1. A paste shaped as a wide table is turned into one row per sample before anything reaches the engine: a header line whose first cell is empty or names the time (`Temps (h)`, `Time`, `t`, a unit alone), at least two subject names that are not the name of a long table's column, then lines whose first cell holds a time or names the dose. Blank lines are skipped, a title line above the header and a footnote below are left out, a quoted spreadsheet cell may hold a line break. Cells are copied as written (decimal comma, `< LQ`, BLQ), an empty cell is a sample not taken. "Several subjects" is switched on when it was off, and the note under the table says what happened (`Pasted 12 subjects × 7 times as … rows`). `data.preview` and `data.import` are unchanged.
2. Dose: an optional `Dose` line in the wide table gives each subject its dose (on the subject's first row, where the worksheet takes it; a unit in the line's first cell, `Dose (mg/kg)`, becomes the dose unit). Without it, "Same dose for every subject" writes one dose on the first row of each subject that has none.
3. Units: a new command `units.check` (read-only, also on the CLI and the MCP server) returns the units recognised for the time, concentration and dose columns, from the same tables the checks use (`caladrius-project/src/units.rs`), and the checks a worksheet with the given units would show. The typed table and the worksheet show a menu next to each unit cell with that list; the cell stays free text; the typed table shows the engine's checks as soon as the person leaves a unit cell.

## Allowed files

`crates/caladrius-ui/src/{entry.rs,entrywide.rs,entryflow.rs,unitpick.rs,sheet.rs,app.rs (field, two call sites),lib.rs,tests_entry.rs}`, `crates/caladrius-ui/examples/snapshot.rs`, `crates/caladrius-project/src/{units.rs,lib.rs,tests.rs}`, `crates/caladrius-engine/src/{commands/units.rs,commands/mod.rs,tests.rs,tests_units.rs}`, the card, INDEX, LOG.

## Completion criterion

`cargo test --workspace` passes with new tests, among them: a synthetic wide table (three subjects, decimal commas, a `< LQ`, a missing sample, a Dose line) pasted gives the same `export.table`, `data.describe` and NCA of every subject as the same data imported from a long CSV file and as the long table typed; without a Dose line, "Same dose for every subject" gives the NCA of the file with that dose; pastes that are not wide (no time header, one subject column, a long header, a gap in the header) are spread as before; every unit listed by `units.check` passes the checks and `mg/kg` is among the doses. fmt, clippy -D warnings, xtask layers, lint, review, wasm green; `docs/conformance.md` unchanged. Snapshot scenes 49 and 50 looked at.

## Thread

- 2026-10-22 interface: created at abdou's request (project thread "Collage d'un tableau large dans la saisie Caladrius"). Branch `claude/project-thread-78zn85`. The data of the report are not used anywhere: every test and scene uses invented values.
- 2026-10-22 interface: implemented. `entrywide.rs` reads a wide paste (pure function over the pasted cells, 4 unit tests); `entry.rs` parses a tabbed paste with spreadsheet quotes, turns a wide one into rows (`paste_wide`), adds `fill_dose` and the "Same dose for every subject" line, the unit menus and the unit checks; `entryflow.rs` asks `units.check` once for the list and again when a unit changed and its cell lost the focus; `unitpick.rs` is the unit cell with its menu, used by the typed table and the worksheet (`sheet.rs`, a pick sends `data.set_column`). Engine: `units.check` (after `data.set_cell` in the command table), `caladrius_project::accepted_units` built from the mass, volume and time tables that `unit_warnings` and `derived_units` now read (same behaviour, the existing unit tests unchanged). Recognised: time s, min, h, d; mass pg, ng, µg, mg, g, kg; volume µL, mL, dL, L; concentration every mass/volume; dose every mass and every mass/kg (mg/kg included); other spellings ug, mcg, uL, ul, ml, dl, l, sec, hr, hour, hours, day, days. Not done: a long paste whose header holds a digit (`Time  S1`) is still read as data, as in T-103 (the header rule is "a first line without a digit"); the engine's message names the unit without its spaces (`mgperkg`), as for a file.
