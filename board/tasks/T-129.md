# T-129: Remove vendor-derived material

- **Role:** orchestrator
- **State:** done
- **Depends on:** none

## Goal

The repository rests on public sources (published literature, PKNCA, other open tools). It does not keep a private comparison with a commercial pharmacokinetic program, rules whose only source was a screen, or instructions to read that program's documentation or exports.

## Allowed files

The living contract, specifications, validation report, oracle notes, lint, the private-oracle loader and its tests, and this card.

## Completion criterion

`cargo test --workspace` passes, and `cargo xtask layers`, `lint`, `review`, `wasm`, `conformance` and `digest` pass. `docs/conformance.md` is unchanged. Numeric results of the public oracles are unchanged.
