## Goal

Each start creates a new `MCPClient`, and therefore a new in-memory engine project (`../agent/apothicaire.py:338`), but `_load_refs` reloads the old references (`:351`). Worksheet and analysis ids are handed out again, so an old `{{call_N}}` no longer matches what the engine holds.

Tie each reference to the engine instance that produced it (session id or project hash) and refuse a reference from another instance. Alternatively, save the engine project and reload it together with the references.

`../agent/apothicaire.py`, `../agent/tests/test_agent_gate_v2.py`, the card.

`python -m unittest discover -s tests` passes in `../agent`. Test: restart the agent on a `refs.jsonl` from a previous session; a reference to it gives a finding (or resolves against the reloaded project).
